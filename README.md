# SVU Status

Static React status page for Syrian Virtual University services. The UI is built with Vite, TypeScript, Tailwind, shadcn/ui, and OpenStatus registry blocks. Status data is generated by GitHub Actions and published as JSON to a separate `status-data` branch.

## Local Development

```bash
npm install
npm run check:status
npm run dev
```

The app reads `VITE_STATUS_DATA_URL` when present. Production is configured to read `https://raw.githubusercontent.com/shadi-almilhem/svustatus/status-data/status.json`. Without an env var, local development falls back to `public/status.json`.

## Status Checks

Monitors are configured in `monitor.config.json`. The checker uses HTTP `2xx` or `3xx` within 20 seconds as up, retries each site up to 3 times, keeps 45 days of hourly history, and outputs OpenStatus-friendly daily bar data.

```bash
npm run check:status
npm run test
npm run lint
npm run build
```

## GitHub Actions Data Branch

`.github/workflows/status-check.yml` runs hourly and on manual dispatch. It checks out the app, restores or creates the `status-data` branch, writes `status.json`, and pushes only that file to `status-data`.

Set Cloudflare Pages to deploy the normal app branch only:

- Build command: `npm run build`
- Build output directory: `dist`
- Environment variable: `VITE_STATUS_DATA_URL=https://raw.githubusercontent.com/shadi-almilhem/svustatus/status-data/status.json`

Keep the repository public, or make the `status-data` JSON publicly reachable some other way, so the static Cloudflare page can fetch it without secrets.
